MOTHERBOARD — КОМПЬЮТЕРИЙН ГОЛ СУУРЬ

Эх хавтан (motherboard) нь CPU, RAM, GPU, SSD болон бусад төхөөрөмжийг хооронд нь холбож, мэдээлэл солилцох боломж олгодог компьютерийн үндсэн плат юм.

Яагаад чухал вэ?

  • Нийцэл: CPU-ийн socket, RAM-ийн DDR4/DDR5 төрөл, өргөтгөлийн холболтуудыг тодорхойлно.
  • Өргөтгөл: PCIe, M.2 болон SATA холболтоор GPU, SSD зэрэг эд ангийг нэмэх боломжийг олгоно.
  • Тогтвортой ажиллагаа: Тэжээлийн хэлхээ (VRM), хөргөлт, BIOS-ийн дэмжлэг нь системийн найдвартай ажиллагаанд нөлөөлнө.
  • Ирээдүйн шинэчлэл: Socket, chipset, RAM slot болон BIOS-ийн дэмжлэг нь дараа нь ямар эд ангиар шинэчлэх боломжтойг хязгаарлана.

Compatibility checklist

ХУДАЛДАН АВАХЫН ӨМНӨ ШАЛГАХ ЗҮЙЛС

  • CPU socket болон BIOS-ийн CPU support list
  • RAM төрөл: DDR4 эсвэл DDR5
  • Case-ийн ATX / micro-ATX / mini-ITX дэмжлэг
  • M.2 slot, SATA портын тоо
  • GPU-ийн PCIe slot болон зай
  • PSU-ийн 24-pin, CPU EPS холболт

FAQ

ТҮГЭЭМЭЛ АСУУЛТ

AM5 эх хавтан DDR4 RAM дэмжих үү?

Үгүй. AMD AM5 desktop платформ DDR5 санах ой ашигладаг.

Chipset ба socket ижил ойлголт уу?

Үгүй. Socket нь CPU-ийн физик холболт, chipset нь эх хавтангийн боломж, холболтод нөлөөлдөг удирдлагын бүрэлдэхүүн юм.

ATX board бүх case-д багтах уу?

Үгүй. Case нь ATX form factor дэмждэг эсэхийг шалгана.

DDR5 RAM-г DDR4 slot-д хийж болох уу?

Болохгүй. Хоёр стандартын slot болон pin байрлал өөр.
