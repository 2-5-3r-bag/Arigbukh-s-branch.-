MEMORY / STORAGE

RAM & SSD

DDR4, DDR5 RAM болон SATA, NVMe SSD загваруудыг нэг дор харьцуул.

Каталог үзэх ↓
RAM нь эх хавтангийн DDR төрлөөр нийцнэ. SSD нь DDR4/DDR5 бус SATA эсвэл PCIe/NVMe интерфэйсээр нийцдэг. M.2 слоттой эсэх болон PCIe үеийг шалга.
