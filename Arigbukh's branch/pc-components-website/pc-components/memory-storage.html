NVMe SSD
02 / Permanent storage

SSD — ХАДГАЛАХ ТӨХӨӨРӨМЖ

NVMe SSD нь PCIe интерфэйс ашигладаг бөгөөд SATA SSD-ээс өндөр дараалсан дамжуулалтын хурдтай байж болно. Гэхдээ бодит ажиллагаа нь workload-оос хамаарна.

  • M.2 нь физик хэлбэр; бүх M.2 төхөөрөмж NVMe биш
  • NVMe нь PCIe-д зориулсан storage протокол
  • Хурд, багтаамж, TBW, баталгааг харьцуул
